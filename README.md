## 📖 ภาพรวมโครงการ (Project Overview)

แอปพลิเคชันสายมูยุคใหม่ที่ผสาน **ศาสตร์ความเชื่อโบราณ (โหราศาสตร์ไทย & โหงวเฮ้ง & ฮวงจุ้ยสรีระ)** เข้ากับ **เทคโนโลยีสมัยใหม่ (Computer Vision & Personal Styling Intelligence)** ในรูปแบบ Interactive Web Prototype ที่ออกแบบตามหลักการ **Hallmark (Anti-AI-Slop)** เพื่อสร้างประสบการณ์ใช้งานระดับ *Luxury Editorial* ปราศจากองค์ประกอบที่ดูเป็นเทมเพลตสำเร็จรูป

## 🔮 สรุป 4 ฟังก์ชันหลัก (Core Modules)

### 1. User Profiling (ระบบนำเข้าข้อมูล)
* รองรับการนำเข้าภาพถ่าย 2 มุมมอง: **ภาพถ่ายใบหน้า (Face Scan)** และ **ภาพถ่ายสรีระเต็มตัว (Body Scan)**
* ระบบบันทึกข้อมูลดวงชะตาไทย: วัน/เดือน/ปีเกิด, เวลาตกฟากที่แม่นยำ (Solar True Time) และภูมิลำเนาเพื่อผูกดวงลัคนาราศี
* รองรับเคสตัวอย่าง 2 เพศ:
  * 👩 **01 / สตรี:** คุณพิมพ์พิชชา (ลัคนาเมถุน / ธาตุลม-น้ำ / Warm Autumn / Wave Type)
  * 👨 **02 / บุรุษ:** คุณกฤติน (ลัคนาสิงห์ / ธาตุไฟ-ดิน / Deep Winter / Straight Type)

### 2. Physical AI & Image Analysis (วิเคราะห์ภาพลักษณ์และสรีระ)
* **Face Analysis x โหงวเฮ้ง:** ตรวจจับโครงหน้าและจุดพิกัด 5 วังโหงวเฮ้ง ภายใต้แนวคิด *"รูปหน้าและสัดส่วนใบหน้าคือ ประตูระบายและเก็บทรัพย์"* แนะนำการเปิดหน้าผาก คอนทัวร์สันจมูก ไฮไลต์พวงแก้ม พร้อมเลือก ทรงผม เมคอัพ และกรอบแว่นตา
* **Body Analysis x จัดฮวงจุ้ยโครงสร้าง:** วิเคราะห์กระดูกตามหลัก Straight / Wave / Natural เพื่อ *"แก้จุดบล็อกและขยายจุดเฮง"* พร้อมวัดอัตราส่วนสมดุล Yin / Yang Balance
* **Seasonal Color Analysis:** ประเมินโทนสีผิวและอันเดอร์โทน (Skin Tone & Undertone) เพื่อแมตช์พาเลตต์เฉดสีเครื่องแต่งกาย

### 3. Astrology & Energy Profile (คำนวณพลังงานออร่าและดวงดาว)
* แสดงผลสนามพลังงานชีวภาพ **Aura Field** แบบนุ่มนวล มิติธรรมชาติ ตามสีมงคลประจำดวงชะตาจริง
* วัดดัชนีพลังงาน 4 เสาหลัก: *การเงิน-โชคลาภ, อำนาจ-บารมี-การงาน, เสน่ห์-เมตตามหานิยม, สุขภาพ-แคล้วคลาด*
* ประมวลผลสมดุลธาตุทั้ง 5 (ดิน น้ำ ลม ไฟ ทอง) พร้อมระบุธาตุพร่องและช่วงเวลาทอง (Golden Window)

### 4. Fashion Recommendation (แนะนำเครื่องแต่งกาย Complete Look)
* แนะนำการแต่งกายแบบครบชุด (เสื้อผ้า, เครื่องประดับมูเตลู/อัญมณี, แว่นตา, รองเท้า, เมคอัพ/ทรงผม)
* ครอบคลุม 4 โอกาสหลักตามข้อกำหนด:
  1. 💼 **Professional:** การทำงาน & เจรจาธุรกิจเชิงกลยุทธ์
  2. 🏛️ **Formal & Ceremonial:** งานพิธีการระดับเกียรติยศ & งานทางการ
  3. ✨ **Social & Evening:** งานเลี้ยงสังสรรค์ & บทสนทนาค่ำคืนส่วนตัว
  4. 📿 **Sacred & Sanctuary:** กิจกรรมมงคล & การรับพลังงานบริสุทธิ์ ณ สถานศักดิ์สิทธิ์
* ระบบถอดรหัสเหตุผลทางฮวงจุ้ยและดวงดาว (Astro-Feng Shui Intelligence) และแคตตาล็อกสินค้าพร้อมราคา

## 🎨 สถาปัตยกรรมการออกแบบ (Hallmark Anti-AI-Slop Architecture)

* **OKLCH Color Space:** ใช้โทนสี Base Warm Obsidian (`oklch(14% 0.008 55)`) และสีหมึก Solid Chalk พร้อมสี Accent ทองสุริยะ (Celestial Gold) ควบคุมพื้นที่ไม่เกิน 3%
* **2+1 Typography Discipline:**
  * *Display Face:* `Cormorant Garamond` ผสาน `Noto Serif Thai` (Roman เท่านั้น)
  * *Body Face:* `Geist` ผสาน `IBM Plex Sans Thai` (คุม Measure 45–65ch)
  * *Outlier Face:* `Geist Mono` สำหรับสถิติ พิกัดดวงดาว และองศาดวง
* **No Re-drawn Chrome:** ปราศจากกรอบมือถือจำลองของเล่น แสดงผลเป็น Responsive Web Application แท้จริง
* **No Emoji Clutter:** นำเสนอด้วยความสุขุมและรหัสระบบมาตรฐาน เช่น `WLTH-01`, `01 / Coiffure`

## 🚀 วิธีการเปิดใช้งาน (Getting Started)

1. Clone คลังเก็บข้อมูลนี้:
   ```bash
   git clone https://github.com/66110063-boop/POC.git
   cd POC
   ```

2. รัน Local Web Server (ด้วย Python):
   ```bash
   python -m http.server 8080
   ```
   หรือดับเบิลคลิกเปิดไฟล์ `index.html` ผ่านเว็บเบราว์เซอร์ (Chrome / Edge / Safari) ได้ทันที

3. เข้าชมผ่าน URL:
   ```
   http://localhost:8080
   ```
